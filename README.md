# Instituto Arara Azul - MVP

Sistema web desenvolvido para ajudar responsáveis e voluntários do Instituto Arara Azul a organizar e acompanhar atividades.

## Tecnologias

- Python 3.12
- Flask
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Login de usuário
- Cadastro de atividades
- Listagem de atividades
- Alteração de status
- Exclusão de atividades
- Mensagens de sucesso e erro

## Como executar

Instale as dependências:

```bash
pip install -r requirements.txt
